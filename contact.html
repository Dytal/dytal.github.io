FEEDBACK & SUPPORT

Contact Sky Hopper

Bug reports are most useful when another person can follow the same steps and see the same result. Use the project issue tracker for game bugs and feature requests.

Report a game bug

When you report a problem, include the page URL, browser and version, device type, game mode, what you expected to happen, what actually happened, and the steps required to reproduce it. For the Arcade relic overlap issue, mention whether a relic rendered inside a gate, touched its glow or changed symbol while moving.

Open bug / feature issue tracker ↗Developer profile ↗

Keep reports safe

  • Never include your password, confirmation link, authentication token or secret API key.
  • Do not publish personal details, email addresses or private account information in a public issue.
  • For a visual bug, a screenshot or short screen recording can help, but remove account and personal information first.

Privacy and account requests

Account deletion and private data requests should be handled through a private contact channel maintained by the site owner, not a public GitHub issue. This repository does not hard-code a support email address. The owner should publish and monitor a private contact method before inviting users to create accounts or seeking advertising approval.

For details about stored data, read the Privacy Notice. For the creator and project details, read About Sky Hopper.
